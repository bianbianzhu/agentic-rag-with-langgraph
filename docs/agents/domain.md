# Domain Docs

This repository uses a single domain context.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read ADRs under `docs/adr/` that affect the area being changed.
- Proceed silently when an expected domain document does not exist.

## Layout

```text
/
├── CONTEXT.md
├── docs/
│   └── adr/
└── src/
```

## Vocabulary

Use the canonical terms from `CONTEXT.md` in issue titles, designs, tests, and implementation. Flag work that contradicts an existing ADR instead of silently overriding it.
